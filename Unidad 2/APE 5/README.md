# APE 5 · Generador congruencial lineal

Se implementó el mismo LCG en Python y Java. Los programas generan 10 000 valores por semilla y muestran las primeras 20 observaciones, la media, la varianza y el período teórico.

- [Proyecto en Python](Proyecto_python/README.md)
- [Proyecto en Java](Proyecto_java/README.md)
- [Referencias de la práctica](referencias.bib)

Para comparar las salidas, usa las mismas semillas y cantidad en ambos programas. Las huellas SHA-256 correspondientes a cada semilla deben coincidir. Con `--exportar`, cada programa guarda un CSV y dos gráficas SVG.
